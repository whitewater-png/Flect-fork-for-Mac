## Flect-for-Mac 0.3.0（日本語）

*English follows below. / 英語版は下にあります。*

0.2.0 からの変更は、**PDF のページ操作、Web ダウンロード（既定はオフ）、削除を伴う処理の安全性の強化**です。ファイルの扱い（元ファイルは変更しない）は変わりません。

### 変更点
- **PDF のページ操作。** **分割**（1 ページずつ、または指定ページを取り出す）、**回転**（90・180・270 度）、**ページ削除**。PDFKit で処理し、必ず新しいファイルに書き出します。ページ指定（`1-3, 5, 8-`、全角入力も可）はダイアログで入力します。暗号化された PDF は理由を示して断ります。
- **Web ダウンロード（既定はオフ）。** **ファイル → URL からダウンロード…** で、動画（最高画質、または 1080p / 720p / 480p まで）か音声（MP3）をダウンロードフォルダに保存します。ご自身で入れた `yt-dlp` と ffmpeg を使い、**設定 → ダウンロード**でオンにします。Flect は yt-dlp を同梱も自動取得もせず、ログイン・cookie・DRM の処理もありません。保存する権利のあるものだけを、各サイトの利用規約に従ってご利用ください。
- **右クリックでダウンロード。** Finder で `.webloc` / `.url` を選んで **Flect: Link Download video**、またはどのアプリでも Web アドレスの文字を選んで **サービス → Flect でダウンロード**（設定は固定: 最高画質・MP4・保存先は設定のフォルダ）。Quick Actions は **42 個**になりました（0.2.0 は 38 個）。
- **削除を伴う処理（重複削除・空フォルダ削除）の安全性を大きく強化。** 同じファイルを重複として出してしまう問題、実行直前に変更されたファイルを削除してしまう問題、確認後にフォルダが入れ替えられた場合の誤削除などを修正しました。選んだ項目そのもの、リンク先、OS の付随ファイル（`._*`、`.DS_Store` など）は対象にしません。詳しくは `CHANGELOG.md` と `SECURITY.md`。
- **起動まわりの安全性。** `--task` / `--input` で渡せる内容を厳しく制限し、Quick Action が書く選択ファイルは NUL 区切りになりました。**更新後は Quick Actions を入れ直してください**（はじめに → **もう一度インストール**）。複数選択で古い Quick Action は断られます。
- **JAR 逆コンパイルは常にサンドボックス内で実行。** サンドボックスを使えないときは、保護なしで動かさずに停止します。
- **コマンドライン:** `-o key=value` が、タスクの同じオプションを上書きします。
- **メッセージ:** プライバシー保護で読めない項目を「存在しない」とは言わず、許可の手順を示します。サンドボックスや削除失敗の理由も表示します。

### オンにする必要があるもの
- **新しい右クリック項目（Link Download video など）:** 最初は**オフ**です。アプリを置き換えてから Quick Actions を入れ直し、システム設定 → 一般 → ログイン項目と機能拡張 → Finder の (i) でオンにしてください。
- **サービス「Flect でダウンロード」:** システム設定 → キーボード → キーボードショートカット… → サービス。
- **Web ダウンロードそのもの:** 設定 → ダウンロード（`brew install yt-dlp`）。

### 通信について
0.2.0 から変わりません。Web ダウンロードは、あなたがオンにして始めたときだけ、yt-dlp 経由で指定したアドレスに接続します。

### インストール
**macOS 14 以降・Apple Silicon** が必要です。手順は 0.2.0 と同じです。`Flect-for-Mac-macos-arm64.dmg`（または `.zip`）をダウンロードし、`.sha256` で検証して、**Flect-for-Mac** を **Applications** へドラッグ（古い版は置き換え。設定は引き継がれます）。ビルドは **ad-hoc 署名で公証していない**ため、最初の 1 回だけ許可が必要です（README の手順）。そのあと **はじめに** タブで Quick Actions を入れ直します。

### 既知の制限
- 公証していません。Intel Mac は未対応・未検証です。
- ショートカット（Shortcuts.app）の「アクション」は、このビルドでは使えません（`docs/shortcuts.md`）。
- Web ダウンロードの画質上限は、サイトが高さを報告する場合だけ効きます。
- 永久削除でも、FAT で同じサイズのまま 2 秒以内に書き換えられた場合（exFAT は 10 ms）は、エンジンの確認からごみ箱への移動までの間では検知できません（`SECURITY.md`）。ごみ箱へ移す場合は戻せます。
- そのほかは 0.2.0 の「既知の制限」と同じです。

## Flect-for-Mac 0.3.0 (English)

What changed since 0.2.0: **PDF page tools, web download (off by default), and much safer deleting tasks**. How your files are handled (originals are never modified) is unchanged.

### What's new
- **PDF page tools.** **Split** (one file per page, or extract the pages you list), **Rotate** (90, 180, 270 degrees) and **Delete pages**. They use PDFKit and always write new files. The page list (`1-3, 5, 8-`; full-width digits work) is entered in a dialog. Encrypted PDFs are refused with a reason.
- **Web download (off by default).** **File → Download from URL…** saves a video (best quality, or capped at 1080p / 720p / 480p) or its audio as MP3 into your Downloads folder, using a `yt-dlp` and ffmpeg you install yourself. Turn it on under **Settings → Download**. Flect never bundles or fetches yt-dlp and has no login, cookie or DRM handling. Download only what you have the right to save and follow each site's terms.
- **Right-click downloads.** Select a `.webloc` or `.url` file in Finder and run **Flect: Link Download video**, or select a web address as text in any app and choose **Services → Download with Flect** (fixed settings: best quality, MP4, your download folder). There are now **42 Quick Actions** (38 in 0.2.0).
- **Much safer Remove Duplicate and Remove Empty.** Fixed: a file offered as a duplicate of itself, files changed right before removal being deleted, and a wrong file deleted when a folder was swapped after the check. Items you selected, link targets and OS bookkeeping files (`._*`, `.DS_Store`…) are never touched. See `CHANGELOG.md` and `SECURITY.md`.
- **Launch hardening.** What `--task` / `--input` may carry is tightly limited, and Quick Actions now write the selection NUL-separated. **Reinstall the Quick Actions after updating** (Getting started → **Install again**); older Quick Actions are refused for more than one selected item.
- **JAR decompile always runs sandboxed.** If the sandbox cannot be set up, the task stops instead of running unprotected.
- **Command line:** `-o key=value` overrides the same option in the task.
- **Messages:** an item hidden by macOS privacy protection is no longer reported as missing, and the steps to allow it are shown; sandbox and removal-failure reasons are shown too.

### What you have to switch on
- **The new right-click items (Link Download video…):** **off** at first. Replace the app, reinstall the Quick Actions, then switch them on in System Settings → General → Login Items & Extensions → Finder (i).
- **The Service "Download with Flect":** System Settings → Keyboard → Keyboard Shortcuts… → Services.
- **Web download itself:** Settings → Download (`brew install yt-dlp`).

### About network use
Unchanged since 0.2.0. Web download connects, through yt-dlp, to the address you give, only when you have switched it on and start it.

### Install
Requires **macOS 14 or later on Apple Silicon**. Same steps as 0.2.0: download `Flect-for-Mac-macos-arm64.dmg` (or the `.zip`), verify it with the `.sha256`, and drag **Flect-for-Mac** onto **Applications** (replaces the old version; settings are kept). The build is **ad-hoc signed, not notarized**, so allow it once as described in the README. Then reinstall the Quick Actions on the **Getting started** tab.

### Known limitations
- Not notarized. Intel Macs are not supported or tested.
- The Shortcuts.app actions are not available in this build (`docs/shortcuts.md`).
- The web download quality cap applies only when the site reports video heights.
- With permanent deletion, a same-size rewrite within FAT's 2-second time resolution (10 ms on exFAT) cannot be detected between the engine's check and the move or removal (`SECURITY.md`). Moves to the Trash can be undone.
- Everything else is as in the 0.2.0 known limitations.
