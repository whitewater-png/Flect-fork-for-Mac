## Flect-for-Mac 0.1.2（日本語）

*English follows below. / 英語版は下にあります。*

0.1.1 からの変更は、**新しいバージョンがないかを確認できるようになった**ことです。処理の内容は変わりません。

### 変更点
- **更新の確認を追加しました。** 設定の **はじめに** タブの **4. アップデート** で **更新を確認** を押すと、新しいリリースがあるか調べて、あればバナーと「ダウンロードページを開く」ボタンを出します。設定ウィンドウを開いたとき、1 日に 1 回自動で確認するオプションもあります（**初期はオフ**）。
- 自動でダウンロードやインストールはしません。新しいバージョンは、ご自分でダウンロードして、Applications のアプリと置き換えてください（設定は引き継がれます）。
- 通知を受け取るには、GitHub の **Watch → Custom → Releases**、またはフィード `https://github.com/whitewater-png/Flect-fork-for-Mac/releases.atom` も使えます。

### 通信について（0.1.1 までの説明からの変更）
0.1.1 までは「アプリは通信しない」としていました。0.1.2 では、**あなたが始める（またはオンにした）更新の確認だけ**が通信します。`api.github.com` への HTTPS 1 回で、あなたや Mac の情報は何も送りません。返ってきた答えは、このリポジトリの `vX.Y.Z` 形式のリリースのときだけ受け付けます。ほかの処理は、これまでどおり通信しません。

### インストール
**macOS 14 以降・Apple Silicon** が必要です。

1. この Release から `Flect-for-Mac-macos-arm64.dmg`（または `.zip`）をダウンロードします。`.sha256` で検証できます。
2. `.dmg` を開き、**Flect-for-Mac** を **Applications** へドラッグします。
3. Flect-for-Mac を開きます。ビルドは **ad-hoc 署名で公証していない**ため、macOS が警告したら、最初の 1 回だけ許可します:
   - macOS 15 以降: 一度開こうとして、出た表示を閉じ（「ゴミ箱に入れる」は押さない）、**システム設定 → プライバシーとセキュリティ →「このまま開く」**（パスワードを聞かれます。開こうとしてから約 1 時間だけ押せます）。
   - macOS 14: アプリを右クリック →「開く」→「開く」。
4. **「はじめに」** タブの **クイックアクションをインストール** → **Finder の設定を開く** で、Flect の項目をオンにします。
5. 同梱していない外部ツールを入れます: アプリの設定の **必要なツール** タブ、または `~/Applications/Flect-for-Mac.app/Contents/Resources/scripts/setup-deps.sh`（`/Applications` に入れた場合はそのパス。インストール前に確認します）。

ターミナルで入れたい場合（zip）:
```bash
shasum -a 256 -c Flect-for-Mac-macos-arm64.zip.sha256
unzip Flect-for-Mac-macos-arm64.zip && mv Flect-for-Mac.app ~/Applications/
xattr -dr com.apple.quarantine ~/Applications/Flect-for-Mac.app
~/Applications/Flect-for-Mac.app/Contents/Resources/flect-tools --out ~/Library/Services
killall Finder
```

### できること
画像（リサイズ、圧縮、回転、HEIC を含む変換、OCR、メタデータ削除、背景除去）、動画・音声（リサイズ、トリミング、サムネイル、圧縮、回転、変換、音声の取り出し、字幕）、PDF（プレビュー、結合、PNG/JPG/テキスト化）、テキスト・JSON、フォルダ（重複、空フォルダ、ツリー表示、分析、リネーム、圧縮）、アーカイブ、JAR のデコンパイル。

元のファイルは変更しません。結果は元ファイルの隣に新しいファイルとして作られます。削除はごみ箱へ移動します。

### 既知の制限
- 公証していません（上記）。ダウンロード直後の警告の文面は macOS のバージョンで異なります。Intel Mac は未対応・未検証です。
- 字幕には、`whisper` フィルタ付きの ffmpeg（Homebrew の `ffmpeg-full`）と、`scripts/fetch-whisper-model.sh` で入れるモデルが必要です。CPU のみの設定は、自動（GPU）よりはるかに遅くなります。
- `whisper` の無い通常の `ffmpeg` では、字幕を確認していません。
- 画像を再エンコードするとき、メタデータ（EXIF/ICC）は引き継がれません。EXIF の向きは画素に反映されます。Windows 版とは異なります。
- 重複検出の「先頭バイトのハッシュ」モードは、意図的に緩い判定です。既定は全内容の比較です。

### セキュリティ
処理は別プロセスの Rust で行います（`unsafe` 禁止）。外部ツールは固定フォルダから、引数配列で起動します。アーカイブの展開では、パス・トラバーサル、リンク、圧縮爆弾を拒否します。既存のファイルは上書きしません。アプリは、あなたが始める（またはオンにした）更新の確認を除いて、ネットワーク接続をしません（確認は `api.github.com` への HTTPS 1 回で、何も送りません）。不具合や質問は Issues へ。脆弱性は **Security → Report a vulnerability** から非公開で報告してください。

## Flect-for-Mac 0.1.2 (English)

What changed since 0.1.1 is that **the app can now check whether a newer version exists**. What the app does with your files is unchanged.

### What's new
- **Update check.** On the **Getting started** tab, **4. Updates** → **Check for updates** looks for a newer release and, if there is one, shows a banner and an "Open the download page" button. An optional check once a day when the settings window opens is **off by default**.
- Nothing is downloaded or installed automatically. Download the new version yourself and replace the app in Applications (your settings are kept).
- To be notified instead, use GitHub's **Watch → Custom → Releases**, or subscribe to the feed `https://github.com/whitewater-png/Flect-fork-for-Mac/releases.atom`.

### About network use (changed from the 0.1.1 notes)
Up to 0.1.1 the app made no network connections. In 0.1.2 **only the update check you start (or switch on)** connects: one HTTPS request to `api.github.com` that sends nothing about you or your Mac, and whose answer is accepted only if it is a plain `vX.Y.Z` release of this repository. Everything else still makes no connection.

### Install
Requires **macOS 14 or later on Apple Silicon**.

1. Download `Flect-for-Mac-macos-arm64.dmg` (or the `.zip`) from this release. Verify it with the `.sha256`.
2. Open the `.dmg` and drag **Flect-for-Mac** onto **Applications**.
3. Open Flect-for-Mac. The build is **ad-hoc signed, not notarized**; if macOS warns, allow it once:
   - macOS 15 or later: try to open it, close the message (do not click "Move to Trash"), then **System Settings → Privacy & Security → Open Anyway** (asks for your password; available for about an hour after the attempt).
   - macOS 14: right-click the app → **Open** → **Open**.
4. On the **Getting started** tab: **Install the Quick Actions**, then **Open the Finder settings** and switch the Flect items on.
5. Install the tools Flect calls but does not bundle: the app's **Required tools** tab, or `~/Applications/Flect-for-Mac.app/Contents/Resources/scripts/setup-deps.sh` (use that path under `/Applications` if you put it there; it asks before installing).

To install from Terminal (zip):
```bash
shasum -a 256 -c Flect-for-Mac-macos-arm64.zip.sha256
unzip Flect-for-Mac-macos-arm64.zip && mv Flect-for-Mac.app ~/Applications/
xattr -dr com.apple.quarantine ~/Applications/Flect-for-Mac.app
~/Applications/Flect-for-Mac.app/Contents/Resources/flect-tools --out ~/Library/Services
killall Finder
```

### What's included
Images (resize, compress, rotate, convert incl. HEIC, OCR, strip metadata, background removal), video/audio (resize, trim, thumbnail, compress, rotate, convert, extract audio, subtitles), PDF (preview, merge, to PNG/JPG/text), text/JSON, folders (duplicates, empty folders, tree, analyze, rename, compress), archives, JAR decompile.

Your originals are never modified; results are new files next to them. Deletions go to the Trash.

### Known limitations
- Not notarized (see above). The wording of the first-launch warning differs between macOS versions. Intel Macs are not supported or tested.
- Subtitles need an ffmpeg with the `whisper` filter (Homebrew `ffmpeg-full`) and a model from `scripts/fetch-whisper-model.sh`. CPU-only mode is much slower than the automatic (GPU) setting.
- Plain `ffmpeg` builds without `whisper` were not tested for subtitles.
- Metadata (EXIF/ICC) is not carried over when an image is re-encoded; EXIF orientation is applied to the pixels. This differs from the Windows version.
- The "first-bytes hash" duplicate mode is intentionally loose; the default compares full contents.

### Security
Processing runs in a separate Rust process (`unsafe` forbidden); external tools are started with argument arrays from fixed folders; archive extraction rejects path traversal, links and decompression bombs; the engine never overwrites existing files; the app makes no network connections except the update check you start or switch on (one HTTPS request to `api.github.com`, nothing about you is sent). Bugs and questions: open an issue. Report vulnerabilities privately via **Security → Report a vulnerability**.
