## Flect-for-Mac 0.1.0（日本語）

*English follows below. / 英語版は下にあります。*

Finder でファイルを右クリックして、変換・圧縮・リサイズなどができます。[Flect](https://github.com/Konayukiw/Flect)（Windows 版）を、Rust の処理コアと Swift の画面で macOS 向けに作り直したものです。Apache-2.0。

### インストール
**macOS 14 以降・Apple Silicon** が必要です。

1. この Release から `Flect-for-Mac-macos-arm64.zip` と `.sha256` をダウンロードします。
2. 検証してインストールします（ビルドは **ad-hoc 署名で公証していない**ため、初回起動時に macOS が警告します）:
   ```bash
   shasum -a 256 -c Flect-for-Mac-macos-arm64.zip.sha256
   unzip Flect-for-Mac-macos-arm64.zip && mv Flect-for-Mac.app ~/Applications/
   xattr -dr com.apple.quarantine ~/Applications/Flect-for-Mac.app
   ~/Applications/Flect-for-Mac.app/Contents/Resources/flect-tools --out ~/Library/Services
   killall Finder
   ```
3. 同梱していない外部ツールを入れます: `~/Applications/Flect-for-Mac.app/Contents/Resources/scripts/setup-deps.sh`（インストール前に確認します。`--check` は確認のみ）。アプリの設定の **必要なツール** タブからも確認できます。
4. システム設定 → 一般 → ログイン項目と機能拡張 → Finder で、Flect の項目をオンにします。そのあと、ファイルを右クリック → クイックアクション。

バイナリを信用したくない場合は、README の手順で自分でビルドしてください。

### できること
画像（リサイズ、圧縮、回転、HEIC を含む変換、OCR、メタデータ削除、背景除去）、動画・音声（リサイズ、トリミング、サムネイル、圧縮、回転、変換、音声の取り出し、字幕）、PDF（プレビュー、結合、PNG/JPG/テキスト化）、テキスト・JSON、フォルダ（重複、空フォルダ、ツリー表示、分析、リネーム、圧縮）、アーカイブ、JAR のデコンパイル。

元のファイルは変更しません。結果は元ファイルの隣に新しいファイルとして作られます。削除はごみ箱へ移動します。

### 既知の制限
- 公証していません（上記）。Intel Mac は未対応・未検証です。
- 字幕には、`whisper` フィルタ付きの ffmpeg（Homebrew の `ffmpeg-full`）と、`scripts/fetch-whisper-model.sh` で入れるモデルが必要です。CPU のみの設定は、自動（GPU）よりはるかに遅くなります。
- `whisper` の無い通常の `ffmpeg` では、字幕を確認していません。
- 画像を再エンコードするとき、メタデータ（EXIF/ICC）は引き継がれません。EXIF の向きは画素に反映されます。Windows 版とは異なります。
- 重複検出の「先頭バイトのハッシュ」モードは、意図的に緩い判定です。既定は全内容の比較です。

### セキュリティ
処理は別プロセスの Rust で行います（`unsafe` 禁止）。外部ツールは固定フォルダから、引数配列で起動します。アーカイブの展開では、パス・トラバーサル、リンク、圧縮爆弾を拒否します。既存のファイルは上書きしません。アプリはネットワーク接続をしません。不具合や質問は Issues へ。脆弱性は **Security → Report a vulnerability** から非公開で報告してください。

## Flect-for-Mac 0.1.0 (English)

Right-click files in Finder to convert, compress, resize and more. A macOS port of [Flect](https://github.com/Konayukiw/Flect) (Windows) with a Rust processing core and a Swift front end. Apache-2.0.

### Install
Requires **macOS 14 or later on Apple Silicon**.

1. Download `Flect-for-Mac-macos-arm64.zip` and its `.sha256` from this release.
2. Verify and install (the build is **ad-hoc signed, not notarized**, so macOS warns on first launch):
   ```bash
   shasum -a 256 -c Flect-for-Mac-macos-arm64.zip.sha256
   unzip Flect-for-Mac-macos-arm64.zip && mv Flect-for-Mac.app ~/Applications/
   xattr -dr com.apple.quarantine ~/Applications/Flect-for-Mac.app
   ~/Applications/Flect-for-Mac.app/Contents/Resources/flect-tools --out ~/Library/Services
   killall Finder
   ```
3. Install the tools Flect calls but does not bundle: `~/Applications/Flect-for-Mac.app/Contents/Resources/scripts/setup-deps.sh` (asks before installing; `--check` only reports). Or open the app's settings → **Required tools**.
4. Turn on the Flect items in System Settings → Login Items & Extensions → Finder, then right-click a file → Quick Actions.

Prefer not to trust a binary? Build it yourself: see the README.

### What's included
Images (resize, compress, rotate, convert incl. HEIC, OCR, strip metadata, background removal), video/audio (resize, trim, thumbnail, compress, rotate, convert, extract audio, subtitles), PDF (preview, merge, to PNG/JPG/text), text/JSON, folders (duplicates, empty folders, tree, analyze, rename, compress), archives, JAR decompile.

Your originals are never modified; results are new files next to them. Deletions go to the Trash.

### Known limitations
- Not notarized (see above). Intel Macs are not supported or tested.
- Subtitles need an ffmpeg with the `whisper` filter (Homebrew `ffmpeg-full`) and a model from `scripts/fetch-whisper-model.sh`. CPU-only mode is much slower than the automatic (GPU) setting.
- Plain `ffmpeg` builds without `whisper` were not tested for subtitles.
- Metadata (EXIF/ICC) is not carried over when an image is re-encoded; EXIF orientation is applied to the pixels. This differs from the Windows version.
- The "first-bytes hash" duplicate mode is intentionally loose; the default compares full contents.

### Security
Processing runs in a separate Rust process (`unsafe` forbidden); external tools are started with argument arrays from fixed folders; archive extraction rejects path traversal, links and decompression bombs; the engine never overwrites existing files; the app makes no network connections. Bugs and questions: open an issue. Report vulnerabilities privately via **Security → Report a vulnerability**.
