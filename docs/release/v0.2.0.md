## Flect-for-Mac 0.2.0（日本語）

*English follows below. / 英語版は下にあります。*

0.1.2 からの変更は、**共有前の安全化、プリセットと連続処理、コマンドライン、起動方法の追加**です。ファイルの扱い（元ファイルは変更しない）は変わりません。

### 変更点
- **共有前に安全にする（画像）。** **プライバシーチェック**は、JPEG・PNG・WebP に入っている個人情報（GPS の位置、カメラやレンズのシリアル番号、撮影者、日時、ソフト名、埋め込みサムネイル、XMP/IPTC、コメントなど）を一覧にします。何も変更しません。**共有しても安全にする**は、それらを取り除いた `_safe` コピーを新しく作ります（再確認してから書き出し、元は触りません。サイズ変更つきもあります）。HEIC・PDF・動画は未対応です。
- **プリセットと連続処理。** **設定 → プリセット**で、1〜8 段階の処理に名前を付けて保存できます（例:「SNS 用 1080px → 2MB」）。ピッカーに出て、ターミナルからも `flect run --preset 名前` で実行できます。途中のファイルは専用の一時フォルダに置かれ、あとで消えます。書き出されるのは最後の 1 ファイルだけです。
- **よく使う項目の固定と「もう一度」。** ピッカーで右クリック →「先頭にピン留め」。前回の操作は「もう一度」で繰り返せます。
- **出力先フォルダ。** **設定 → 出力先**で、機能ごとに保存先を決められます（空なら元ファイルの隣）。`./Compressed` のような相対パス、絶対パス、`~` が使えます。既存のファイルは上書きしません。
- **重複削除の確認。** 実行前に、残すファイルと削除（ごみ箱）するファイルを一覧で確認できます。既定のボタンは「キャンセル」です。
- **結果と元に戻す。** 実行後に、作成したファイルの一覧と **Finder で表示** / **元に戻す**（その実行で作ったファイルだけをごみ箱へ。変更されていない場合に限る）が出ます。**ファイル → 最近の実行…**に直近 20 回が残ります。処理が終わると通知します（システム設定で許可したとき）。
- **コマンドライン `flect`。** アプリに同梱（`Flect-for-Mac.app/Contents/Resources/flect`）。`flect list`、`flect run <タスク> …`、`--json` など。削除を伴う処理（重複削除・空フォルダ削除）は、`--apply` を付けない限りプレビューだけです。詳しくは `docs/cli.md`。
- **起動方法の追加。** Dock の Flect アイコン（または Flect.app）へのドロップ、**ファイル → 開く…**（⌘O）、サービス「Flect で処理…」。
- **大量処理が速くなりました。** 画像やテキストを複数まとめて処理するとき、並列で実行します（既定 4 本）。結果は入力順に報告し、キャンセルもこれまでどおり効きます。
- **修正:** テキスト → 変換（JSON・CSV・XML など）が「まだ使えません」と返っていた問題。Windows で作った日本語・中国語名の zip（Shift_JIS / GBK）が文字化けして展開される問題。日本語・中国語の画面で、結果の見出しが 1 ファイルのときだけ英語になる問題。
- **安全性の強化:** シンボリックリンクの出力先フォルダを拒否、ハードリンクを使えない場合のコピーで途中の壊れたファイルを残さない、標準出力が閉じたら並列処理を止める、進行型 JPEG の途中に隠れたメタデータを検出して除去、CLI が名前の制御文字をそのまま表示しない。

### オンにする必要があるもの
macOS は新しいものを**オフ**にします。使うには、システム設定で次をオンにしてください（手順は README の「そのほかの起動方法と通知」）。
- **新しい Quick Actions（プライバシーチェック、共有しても安全にする 2 種）:** システム設定 → 一般 → ログイン項目と機能拡張 → Finder の (i)。**サービス**メニューからは、オンにしなくても使えます。
- **サービス「Flect で処理…」:** システム設定 → キーボード → キーボードショートカット… → サービス。
- **完了通知:** システム設定 → 通知 → Flect。

### 通信について
0.1.2 から変わりません。アプリが通信するのは、あなたが始める（またはオンにした）更新の確認だけです（`api.github.com` への HTTPS 1 回で、何も送りません）。

### インストール
**macOS 14 以降・Apple Silicon** が必要です。

1. この Release から `Flect-for-Mac-macos-arm64.dmg`（または `.zip`）をダウンロードします。`.sha256` で検証できます。
2. `.dmg` を開き、**Flect-for-Mac** を **Applications** へドラッグします（古い版は置き換えます。設定は引き継がれます）。
3. Flect-for-Mac を開きます。ビルドは **ad-hoc 署名で公証していない**ため、macOS が警告したら、最初の 1 回だけ許可します:
   - macOS 15 以降: 一度開こうとして、出た表示を閉じ（「ゴミ箱に入れる」は押さない）、**システム設定 → プライバシーとセキュリティ →「このまま開く」**（パスワードを聞かれます。開こうとしてから約 1 時間だけ押せます）。
   - macOS 14: アプリを右クリック →「開く」→「開く」。
4. **「はじめに」** タブの **クイックアクションをインストール** → **Finder の設定を開く** で、Flect の項目をオンにします（38 個）。
5. 同梱していない外部ツールを入れます: アプリの設定の **必要なツール** タブ、または `Flect-for-Mac.app/Contents/Resources/scripts/setup-deps.sh`（インストール前に確認します）。

ターミナルで入れたい場合（zip）:
```bash
shasum -a 256 -c Flect-for-Mac-macos-arm64.zip.sha256
unzip Flect-for-Mac-macos-arm64.zip && mv Flect-for-Mac.app ~/Applications/
xattr -dr com.apple.quarantine ~/Applications/Flect-for-Mac.app
~/Applications/Flect-for-Mac.app/Contents/Resources/flect-tools --out ~/Library/Services
killall Finder
```

### 既知の制限
- 公証していません（上記）。Intel Mac は未対応・未検証です。
- **ショートカット（Shortcuts.app）の「アクション」は使えません。** App Intents のコードは入っていますが、登録情報の生成に完全版の Xcode が必要で、このビルドには含まれていません。代わりに、ショートカットの「シェルスクリプトを実行」から同梱の `flect` を呼んでください（`docs/shortcuts.md`）。
- 共有前の安全化は、JPEG・PNG・WebP（GIF は安全化のみ）が対象です。HEIC・PDF・動画は未対応です。実際のカメラ写真（メーカー独自の拡張データなど）での確認は、合成した画像に限られています。
- 目標サイズ圧縮の事前見積もりはありません。
- 重複削除の確認画面は、スナップショットではありません。「実行」を押すと、もう一度スキャンして実行します。確認後に増えたファイルも対象になります。
- 字幕には、`whisper` フィルタ付きの ffmpeg（Homebrew の `ffmpeg-full`）と、`scripts/fetch-whisper-model.sh` で入れるモデルが必要です。
- 画像を再エンコードするとき、メタデータ（EXIF/ICC）は引き継がれません。EXIF の向きは画素に反映されます。
- 日本語・中国語の追加分の文言は機械的な翻訳を含みます。違和感があれば Issues へ。

### セキュリティ
処理は別プロセスの Rust で行います（`unsafe` 禁止）。外部ツールは固定フォルダから、引数配列で起動します。アーカイブの展開では、パス・トラバーサル、リンク、圧縮爆弾を拒否します。既存のファイルは上書きしません。不具合や質問は Issues へ。脆弱性は **Security → Report a vulnerability** から非公開で報告してください。

## Flect-for-Mac 0.2.0 (English)

What changed since 0.1.2: **safer sharing, presets and chains, a command line, and more ways to start**. How your files are handled (originals are never modified) is unchanged.

### What's new
- **Make files safe to share (images).** **Privacy Check** lists the personal data a JPEG, PNG or WebP carries (GPS location, camera and lens serial numbers, owner/author, timestamps, software, embedded thumbnails, XMP/IPTC, comments) and changes nothing. **Make Safe to Share** writes a new `_safe` copy without it (re-checked before it is written; the original is untouched; a resize variant exists). HEIC, PDF and video are not covered.
- **Presets and chains.** **Settings → Presets** saves named lists of 1 to 8 steps (e.g. "SNS 1080px → 2MB"). They appear in the action picker and run from Terminal with `flect run --preset NAME`. Intermediate files stay in a private temporary folder that is removed afterwards; only the final file is written.
- **Pin and Run again.** Right-click an item in the picker → Pin to top. **Run again** repeats the last operation.
- **Output folders.** **Settings → Output** chooses where each feature writes (empty = beside the original). Relative paths such as `./Compressed`, absolute paths and `~` work. Existing files are never overwritten.
- **Confirm before deleting duplicates.** A preview shows the copy that stays and the copies that go to the Trash; Cancel is the default button.
- **Results and Undo.** After a run, a list of the created files with **Show in Finder** and **Undo** (moves only the files that run created to the Trash, and only if they are unchanged). **File → Recent Runs…** keeps the last 20 runs. A notification tells you when a run finishes (once you allow it in System Settings).
- **Command line `flect`.** Bundled in the app (`Flect-for-Mac.app/Contents/Resources/flect`): `flect list`, `flect run <task> …`, `--json` and more. Tasks that delete (Remove Duplicate, Remove Empty) only preview unless you pass `--apply`. See `docs/cli.md`.
- **More ways to start.** Drop files on the Dock icon (or on Flect.app), **File → Open…** (⌘O), and the Service "Process with Flect…".
- **Faster batches.** Many images or text files are processed side by side (4 workers by default). Results are reported in input order and cancel still works.
- **Fixed:** Text → Convert (to JSON, CSV, XML…) was answered "not available yet"; zip files made on Windows with Japanese or Chinese names (Shift_JIS / GBK) extracted with garbled names; the results header showed English for exactly one file in a Japanese or Chinese UI.
- **Hardening:** symlinked output folders are refused; the copy fallback when hard links are unavailable no longer leaves a truncated file; a closed output pipe stops a parallel batch; metadata hidden between the scans of a progressive JPEG is found and removed; the CLI does not print control characters from file names raw.

### What you have to switch on
macOS leaves new things **off**. To use them, switch these on in System Settings (steps are in the README under "Other ways to start, and notifications"):
- **The new Quick Actions (Privacy Check, Make Safe to Share, and its resize variant):** System Settings → General → Login Items & Extensions → Finder (i). They also work from the **Services** menu without this.
- **The Service "Process with Flect…":** System Settings → Keyboard → Keyboard Shortcuts… → Services.
- **Finish notifications:** System Settings → Notifications → Flect.

### About network use
Unchanged since 0.1.2: the app connects only for the update check you start or switch on (one HTTPS request to `api.github.com`, nothing about you is sent).

### Install
Requires **macOS 14 or later on Apple Silicon**.

1. Download `Flect-for-Mac-macos-arm64.dmg` (or the `.zip`) from this release. Verify it with the `.sha256`.
2. Open the `.dmg` and drag **Flect-for-Mac** onto **Applications** (this replaces an older version; your settings are kept).
3. Open Flect-for-Mac. The build is **ad-hoc signed, not notarized**; if macOS warns, allow it once:
   - macOS 15 or later: try to open it, close the message (do not click "Move to Trash"), then **System Settings → Privacy & Security → Open Anyway** (asks for your password; available for about an hour after the attempt).
   - macOS 14: right-click the app → **Open** → **Open**.
4. On the **Getting started** tab: **Install the Quick Actions**, then **Open the Finder settings** and switch the Flect items on (38 of them).
5. Install the tools Flect calls but does not bundle: the app's **Required tools** tab, or `Flect-for-Mac.app/Contents/Resources/scripts/setup-deps.sh` (it asks before installing).

To install from Terminal (zip):
```bash
shasum -a 256 -c Flect-for-Mac-macos-arm64.zip.sha256
unzip Flect-for-Mac-macos-arm64.zip && mv Flect-for-Mac.app ~/Applications/
xattr -dr com.apple.quarantine ~/Applications/Flect-for-Mac.app
~/Applications/Flect-for-Mac.app/Contents/Resources/flect-tools --out ~/Library/Services
killall Finder
```

### Known limitations
- Not notarized (see above). Intel Macs are not supported or tested.
- **The Shortcuts.app actions are not available.** The App Intents code is in the source, but registering it needs a build with full Xcode, which this build does not have. Use the bundled `flect` in a **Run Shell Script** action instead (`docs/shortcuts.md`).
- Making files safe covers JPEG, PNG and WebP (GIF: sanitising only). HEIC, PDF and video are not covered. It was checked on synthetic images, not on real camera files with vendor-specific data.
- There is no size estimate before compress-to-target-size.
- The duplicate preview is not a snapshot: pressing the confirm button scans again and acts on what it finds then, including files added after you looked.
- Subtitles need an ffmpeg with the `whisper` filter (Homebrew `ffmpeg-full`) and a model from `scripts/fetch-whisper-model.sh`.
- Metadata (EXIF/ICC) is not carried over when an image is re-encoded; EXIF orientation is applied to the pixels.
- Some of the new Japanese and Chinese wording is machine-translated; please open an issue if something reads oddly.

### Security
Processing runs in a separate Rust process (`unsafe` forbidden); external tools are started with argument arrays from fixed folders; archive extraction rejects path traversal, links and decompression bombs; the engine never overwrites existing files. Bugs and questions: open an issue. Report vulnerabilities privately via **Security → Report a vulnerability**.
