## 今回直したもの（未コミット）
- **設定ウィンドウが小さく開く（1-1 ×）:** `AppDelegate.swift` が指定した 760×580 を、SwiftUI の最小サイズ（480×328）が上書きしていた。`host.sizingOptions = []` を追加して直した。副作用として、PDF プレビューも広く開く
- **JAR のデコンパイルが「未実装」（4-1 ×）:** `tasks.rs` の `is_file_task` に `jar.decompile` が無く、エンジンの入口で弾かれていた。1 行追加し、テストを 1 件追加した

## 気づいたこと
- **字幕の Tiny の質:** 番号が 0 から始まる（SRT は 1 から）。2 つ目の字幕の終了時刻が 32 秒で、音声（7.4 秒）より長い。「to dig」のような幻聴が入る。Small では正しい文と時刻になった。字幕は ffmpeg の whisper フィルタの出力そのままなので、番号の振り直しと終了時刻の丸めをエンジン側で行う余地がある
- **VTT の cue に番号 `0` が残る**（許容されるが不要）
- **字幕のエラー文言（2-7、2-8）:** `msg.whisperModelMissing` / `msg.whisperModelMismatch` の `{0}` に、モデルのファイル名ではなく入力ファイル名が入る（「音声認識モデル speech_en.m4a がありません」）
- **不正な言語（2-6）の文言:** 「このメディア形式は許可されていません」で、原因が言語の指定だと分かりにくい
- **CPU のみの字幕（2-12）:** 実時間より遅い（7.4 秒に 26 秒）。実行中は負荷が非常に高くなる（ロードアベレージ 56）。GPU 自動なら 0.8 秒
- **色キーの出力名:** 背景除去は AI なら `_nobg.png`、色キーなら `_keyed.png`（手順書は `_nobg`）
- **設定の保存:** 1 項目を変えて保存すると、他の既定値も明示的に書き出される（例: `ResizeB`、`BackgroundKeyColor`）。リサイズ A に 999 を入れても丸められず保存された
- **失敗時の画面:** 失敗しても見出しが「処理中…」のままで、下に「失敗しました。」と出る
- **強制終了した字幕処理:** 私が 180 秒で強制終了したため、`.Flect-for-Mac-…` という作業フォルダが入力ファイルの隣に残った（正常なキャンセルでは残らない）
- **性能の注記:** 画像は合成の JPEG（約 0.6MB / 枚）、重複は小さなファイルなので、実際の写真・ファイルでは遅くなる可能性がある。動画の差が小さいのは、ソフトウェア側がすでに速いため
- **導入したもの:** `brew install openjdk`（Java 27）を JAR の確認のために入れた。残してある
