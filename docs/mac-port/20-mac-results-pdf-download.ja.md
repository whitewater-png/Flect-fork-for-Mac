# Flect-for-Mac — 20 Mac 実機の確認結果（PDF ページ操作・Web ダウンロード）

チェックリスト [19](19-mac-verification-checklist.ja.md) の実施結果。○ 期待どおり ／ △ 一部のみ・期待と違う ／ × 動かなかった ／ － 省略。

## 結論

**PDF のページ操作（分割・抜き出し・回転・削除）と Web ダウンロードは、実機で期待どおりに動いた。** ファイルが壊れる、元ファイルが変わる、プロセスが残る、といった重大な不具合は見つからなかった。気づいた点は 5 件（下の「見つかった点」）で、うち 2 件は文言・表示の小さな修正、2 件は仕様の確認、1 件は導入手順の注意。

```
対象: claude/exciting-brown-3b2qqy @ 0d503c6（ローカルでビルドして検証。Release の成果物は使っていない）
環境: macOS 27.0.1 (26A434) / Apple M4 Max / ffmpeg 9.0.2 (ffmpeg-full) / yt-dlp 2026.08.19 / 7-Zip 26.04
実施日: 2026-10-22
```

## 検証の方法

- アプリは `scripts/build.sh`（インストールなし）で作り、`dist/` のものを直接起動した。`/Applications` や `~/Applications` の導入済みアプリは置き換えていない。
- 画面の操作（ファイル → 開く…、ダイアログ、設定、メニュー）は Mac の画面で実際に行った。
- 出力 PDF の中身は `scripts/mac-verify/pdf-info.swift`（PDFKit）で、枚数・ページの大きさ・回転・各ページの文字を確認した。
- ダウンロードは、127.0.0.1 のローカルサーバーを使い、外部への通信は D-16 の 1 回だけ（下記）。
- 設定ファイルと Homebrew のリンクを一時的に変えた項目は、確認の直後に元へ戻し、同一であることを確認した（「後始末」）。

## 未確認の項目と理由

- **C-7 / C-8 の向きの目視**: PDF の `rotation` の値（90 / 180 / 270）で確認した。プレビューで見て時計回りかを確かめる作業は残っている。
- **右クリックでの新 3 項目（C-1）**: 新しい項目はオフで追加される。オンにする操作はシステム設定の変更にあたるため行わなかった。サービスメニューと、起動先を置き換えた実行で代わりに確認した。

## 後始末

- **設定ファイル**: 検証のたびに変えた `~/Library/Application Support/Flect-for-Mac/settings.json` は、検証前の内容へバイト単位で戻して確認した。
- **Homebrew のリンク**: D-3 / D-4 / D-17 で `/opt/homebrew/bin` の `yt-dlp`・`ffmpeg`・`ffprobe` のリンクを一時退避し、直後に戻した（3 つとも元のリンク、`ffmpeg -version` が動く）。アンインストールはしていない。
- **クイックアクション**: 41 個を入れたが、旧版で動かないと分かったため、元の 38 個に戻した（バックアップと同一）。
- **誤操作 2 件**: 検証中に、Finder へキー操作が入って `five-pagesのコピー.pdf` ができたこと、タスク一覧のずれで PDF → JPG を誤って実行して `two-pages_p1.jpg` / `p2.jpg` ができたことがあった。どちらもゴミ箱へ移した。
- **ゴミ箱**: 検証で作ったファイル（`sample [sample] (audio).mp3`、`y.txt`、`slow1 [slow1] (test).mp4`、最高画質のダウンロード 1 本 など）は、削除ではなくゴミ箱へ移してある。
- **残してあるもの**: `~/FlectTest`（テスト用ファイルと `c13` `e5` `out` `dl`）、`~/Downloads` の「480p まで」のダウンロード 1 本。`scripts/mac-verify.sh --clean` は実行していない。

## 確認後の対応（2026-10-22）

| 見つかった点 | 対応 |
| --- | --- |
| 1 暗号化 PDF の文言が「結合」専用 | 3 言語とも「処理できません」に変更（`msg.pdfEncrypted`） |
| 2 最近の実行に内部名が出る | 原因は PDF → JPG だけでなく、アプリ側で行う変換（`pdf.convert.PNG/JPG/TXT`、`image.convert.HEIC`）すべてで表示名が無かったこと。「PDF: JPG に変換」のように表示するよう修正（`TaskLabels`、テスト付き） |

| 4 高さの情報が無い動画で画質上限が効かない | 仕様のまま。ダイアログに一文の注記を追加し、チェックリスト D-16 にも明記 |

### D-27 の原因と修正

- **原因**: サービスの `downloadWithFlect`（`EntryPoints.swift`）は、選んだ文字に URL が無いと、`error` に英語の文を入れて**アプリに渡さずに返して**いた。macOS はサービスの `error` の文を通常は表示しないため、利用者には「最初の画面が出るだけ」に見えた。D-22（リンクファイル）は、`startDownloads` が空のアドレスで「Web アドレスが見つかりませんでした。」の画面を出すので、サービスだけが揃っていなかった。
- **修正（案 A）**: 選んだ文字を、URL の有無にかかわらずそのままアプリへ渡す。`startTextDownload` → `startDownloads(urls: [])` が、D-22 と同じ「Web アドレスが見つかりませんでした。」の画面を出す。設定がオフ・yt-dlp 未導入のときは、その案内が先に出る（D-22 と同じ順）。チェックリスト D-27 の期待値も合わせた。
